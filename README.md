# Skill Atlas 1.0.0

Minecraft 1.21.1 · NeoForge 21.1.233 · Java 21。客户端和服务端都需要安装；TinyPinyin 与 Aho-Corasick 已通过 Jar-in-Jar 内置，无需额外安装其他模组。

## 浏览

- 默认按 **K** 打开技能树（可在按键设置中修改）。窗口按屏幕比例占据部分画面，界面大小由客户端配置 `virtualHeight` 控制，不受原版“界面尺寸 1/2/3/4”影响。
- 左侧切换分类，也可以按 Tab / Shift + Tab 或数字键 1 – 9 切换。左键或右键拖动画布平移，滚轮以鼠标为中心缩放（25%～300%），Home 键适应视图，Space 居中视图，0 恢复 100% 缩放。
- 左键点击技能打开详情，Shift + 左键或 Ctrl + 左键直接学习或升级。悬浮显示名称、状态、等级、描述、当前效果、下一级效果、消耗（点数与交付物品，物品数量够时显示绿色、不够显示红色）与前置。
- 搜索框（Ctrl + F）支持名称、描述、别名、ID，中文支持全拼与首字母，例如“力量”可用 `liliang` 或 `ll` 搜到。点击结果会切换分类并定位到技能。
- 左下角只显示当前分类所用点数池的余额。鼠标悬停在左侧分类页签上，可以看到该点数池的获取方式、当前进度和进度说明。
- 工具栏“技能点”查看各点数池的余额、获取方式、进度和进度说明；“帮助”查看操作说明。

## 编辑

拥有编辑权限（默认权限等级 2，可在服务端配置中修改）的玩家可以点击工具栏的编辑按钮进入编辑模式。单人游戏需要开启作弊，或在对局域网开放时允许作弊。

- 右键空白处选择“新建技能”，或双击空白处直接创建。
- 双击技能、Enter 或 F2 打开编辑器，可修改 ID、名称、别名、分类、图标（物品，或贴图路径）、描述、形状与大小、隐藏、解锁条件（全部前置/任一前置）、前置列表与等级。等级列表每行显示消耗与奖励、物品数量，点击“第 N 级”打开单独的界面编辑该级的消耗、奖励和交付物品；行尾按钮可上移、复制、删除该级。
- 技能形状可选圆角方形、方形、圆形、菱形、五边形、六边形、八边形、心形、齿轮和无边框；大小为缩放倍率，范围 0.5–4，1 为标准大小。存档字段为 `shape` 与 `size`，旧版 `major` 字段不再读取。
- 拖动技能移动（默认吸附 8 像素网格，按住 Alt 关闭吸附），方向键按网格移动，Shift + 方向键精细移动。
- 空白处拖动框选，Ctrl + 点击切换选择，Ctrl + A 全选，Ctrl + D 取消全部选择。选中多个技能后右键“批量编辑”，只有勾选了“应用”的分区会覆盖到所有选中技能。
- 按住 Shift 从一个技能拖到另一个技能添加前置；也可以选中多个技能后右键另一个技能，批量“将选中的技能设为前置”“设为选中技能的前置”，或移除这两种前置关系。会形成循环的连线显示为红色并被拒绝。
- 每条前置可填写“等级大于”：填 5 表示前置技能至少达到 6 级，填 0 表示至少达到 1 级。详情显示所需门槛和当前等级；批量编辑、复制粘贴、撤销和联机同步保留门槛。每个前置还可单独选择是否显示连线；关闭后条件仍生效，编辑模式下以虚线显示。
- 隐藏技能在满足前置条件之前不会显示，也不会出现在玩家的搜索结果中。
- Ctrl + C / X / V 复制、剪切、粘贴，Delete 删除（Shift + Delete 不确认直接删除）。粘贴以鼠标位置为中心，ID 冲突时自动改名，选中技能之间的前置会重新指向新副本，指向其他已有技能的前置保留；Ctrl + Shift + V 粘贴时不保留指向其他技能的前置。
- Ctrl + Z 撤销自己的上一次编辑（技能、分类、点数池的增删改与移动都可撤销，最多 50 步，包括被删除对象的各语言翻译）。撤销按对象整体恢复编辑前的状态：如果其他编辑者之后改过同一对象，他的修改会被覆盖。
- 按住 F1 悬停技能显示技能 ID 和坐标；右键技能可“复制 ID”；底部状态栏显示光标所在的画布坐标和已选数量。复制内容同时写入系统剪贴板，可在不同存档、不同服务器之间粘贴。
- 左侧分类栏右键可编辑、上移、下移、删除分类。删除技能或分类时，已学习的玩家会被退还对应点数。
- 每个分类可单独设置背景图片（编辑分类 → 背景），填写贴图路径，例如 `minecraft:textures/block/deepslate.png` 或资源包中的 `skill_atlas:textures/gui/backgrounds/combat.png`。默认按比例铺满画布并居中裁剪；勾选“平铺”后按贴图尺寸重复，并随画布平移和缩放，适合方块贴图。留空或路径无效时使用默认背景 `skill_atlas:textures/gui/canvas.png`。
- 网格只在编辑模式下显示。帮助界面的“编辑快捷键”一节列出了全部编辑快捷键。
- 名称、别名、描述和进度说明直接填写文字即可，支持 `&` 颜色代码（例如 `&a` 绿色）。保存时服务端会按编辑者当前的游戏语言，为该文字自动生成翻译键 `skill_atlas.atlas.<node|category|pool>.<ID>.<字段>`，并写入 `config/skill_atlas/lang/<语言>.json`；`atlas.json` 中只保存键。切换到其他语言再编辑同一字段，会写入该语言的文件，各语言互不覆盖。某语言缺少译文时，按 en_us → zh_cn → 其他语言的顺序回退。
- 技能、分类、点数池的 ID 全局唯一，创建后不可修改，翻译键与 ID 绑定。删除对象时，其翻译会一并清除。

所有修改都发送到服务端校验后再保存并同步给所有在线玩家。多名管理员同时编辑时以服务端为准，客户端发现版本不连续会自动重新同步。

## 技能与奖励

编辑模式下右键画布空白处选择“添加图片”，可插入资源包 PNG 贴图。图片支持拖动、右下角缩放（Shift 保持比例）、右键编辑/调整图片层级/删除和 Ctrl+Z 撤销，随分类保存并同步；玩家需有对应资源包才能看到自定义图片。

每个技能最多 100 级，每级单独设置消耗与奖励。持续性奖励只取当前等级，升级后替换上一级的效果，不会叠加。

| 奖励类型 | 说明 |
| --- | --- |
| 属性 | 任意已注册属性，支持加值、基础值乘算、总值乘算 |
| 周期效果 | 按间隔（刻）给予状态效果，可设置等级、持续时间、是否显示粒子与图标 |
| 效果免疫 | 移除已有的指定效果，并阻止它再次施加 |
| 命令 | 升到该等级时以玩家身份执行一次，权限等级 2，输出不会显示给玩家 |

只有权限等级 2 及以上的编辑者能新增或修改命令奖励；编辑权限配置得更低时，低权限编辑者仍可编辑其他内容。

### 模组自带属性

以下属性默认附加在玩家身上，可以像原版属性一样用作属性奖励，建议使用“加值”。

| 属性 | ID | 效果 |
| --- | --- | --- |
| 回血效率 | `skill_atlas:healing_efficiency` | 所有生命回复量 × (1 + 属性值 / 100)，包括自然回复、再生、瞬间治疗等。最低 -100，即完全无法回复 |
| 经验获取 | `skill_atlas:experience_gain` | 击杀生物掉落的经验 × (1 + 属性值 / 100)，不足 1 点的部分按概率补足。不影响挖矿、熔炼、交易等其他经验来源 |
| 抢夺 | `skill_atlas:looting` | 与抢夺附魔效果相同并叠加在附魔等级上，影响掉落数量、稀有掉落和装备掉落率，弓箭击杀同样生效。小数部分按概率额外 +1 级，例如 2.4 有 40% 的几率按 3 级计算 |
| 时运 | `skill_atlas:fortune` | 与时运附魔效果相同并叠加在工具的时运等级上，只影响方块掉落；工具带精准采集时不生效。小数部分同样按概率补足 |
| 挖掘速度 | `skill_atlas:mining_speed` | 挖掘速度 × (1 + 属性值 / 100)，例如 10 表示快 10%。最低 -100 |
| 石头出矿概率 | `skill_atlas:stone_mineral_chance` | 生存挖掘石头（`minecraft:stone`）时额外获得随机矿物的概率，2 表示 2%，范围 0～100。触发后获得 3 煤炭、1 铁锭、1 金锭或 1 钻石；不改变原有石头掉落，也不重复触发时运的掉落重算 |
| 矿物经验获取 | `skill_atlas:mining_experience` | `#c:ores` 矿物掉落的经验 × (1 + 属性值 / 100)，20 表示多 20%。小数部分按概率补足；原本不掉经验的矿物或精准采集不额外产生经验 |
| 收获经验 | `skill_atlas:harvest_experience` | 每次成功收获成熟作物额外获得的实际经验点数。默认农耕技能每级 +1，最高 +5；支持普通 CropBlock 作物、下界疣、可可豆以及甜浆果采摘 |
| 钓饵 | `skill_atlas:fishing_lure` | 额外钓饵等级，与鱼竿附魔叠加。每级缩短 5 秒随机等待，最低等待 1 秒，不改变咬钩后收杆窗口 |
| 海之眷顾 | `skill_atlas:fishing_luck` | 额外海之眷顾等级，与鱼竿附魔和原版幸运叠加；仍遵守开放水域的宝藏条件 |
| 附魔升级概率 | `skill_atlas:enchanting_cap` | 附魔台生成的附魔等级有概率额外提高 1 级，可突破原版词条等级上限。属性以百分比表示，默认 0，最大 100；默认技能每级 +1%，满级 30%。预览与实际结果使用同一随机种子，仅作用于附魔台生成的结果。三个档位的等级需求、抽取强度及经验等级扣除恢复原版。普通物品最高安全写入等级为 127，附魔书为 255，到达时保持原等级 |
| 额外跳跃高度 | `skill_atlas:jump_height` | 地面起跳时额外增加的高度，单位为格，默认 0，最大 16。根据玩家当前起跳速度和重力换算，保留跳跃药水和方块对起跳的影响；不影响水中起跳 |
| 摔落伤害减少 | `skill_atlas:fall_damage_reduction` | 减少摔落标签伤害的百分比，默认 0，最大 100；在原版计算伤害后按比例减少，保留其他伤害修正 |
| 熔炼速度 | `skill_atlas:smelting_speed` | 增加熔炉、高炉、烟熏炉的加工速度百分比，默认 0，最大 10000；使用小数进度累计，150% 加成使 200 tick 的配方缩短为 80 tick |
| 粗矿翻倍概率 | `skill_atlas:raw_ore_double_chance` | 熔炼 `forge:raw_materials` 内的粗矿时额外获得一份配方产物的概率百分比，默认 0，最大 100；输出格有足够空间时生效，不超堆叠上限 |
| 燃料持续时间 | `skill_atlas:fuel_efficiency` | 新消耗燃料的持续时间增加百分比，默认 0，最大 10000；已点燃的燃料不会因玩家下线或属性变化倒扣时间 |
| 熔炼经验获取 | `skill_atlas:smelting_experience` | 玩家取出产物时炉子释放的经验增加百分比，默认 0，最大 10000；先按原版配方和随机小数结算，再应用倍率 |
| 青金石节省概率 | `skill_atlas:lapis_saving` | 实际附魔成功后不消耗青金石的概率百分比，默认 0，最大 100 |
| 附魔经验返还 | `skill_atlas:enchanting_refund` | 返还附魔台本次实际消耗经验值的百分比，默认 0，最大 100；按等级与经验条前后差计算，返还点数向下取整，不返还技能学习费用 |
| 附魔书复刻概率 | `skill_atlas:book_copy` | 附魔书成功生成后额外获得一个完整相同副本的概率百分比，默认 0，最大 100；背包满时掉在玩家身边 |
| 完整附魔预览 | `skill_atlas:enchanting_insight` | 大于 0 时显示三个档位的全部附魔词条及等级；服务端按真实附魔种子计算，包含附魔升级概率效果 |
| 鞘翅飞行速度 | `skill_atlas:elytra_speed` | 鞘翅滑翔位移的增加百分比，默认 0，最大 10000；不逐 tick 累乘速度，不影响陆地、游泳或创造飞行 |
| 自动补种 | `skill_atlas:crop_replanting` | 大于 0 时，破坏成熟作物后消耗 1 个对应种植物重新种植。优先使用本次掉落，再使用背包与副手；缺种、无支撑或原位置被占用时不补种 |
| 作物增产 | `skill_atlas:harvest_yield` | 成熟作物产物的额外掉落百分比，30 表示多 30%；不足 1 个的部分按概率补足，不增加 `forge:seeds` 种子。支持右键采莓果；胡萝卜、土豆、疣、可可豆和莓果兼作种植物，仍作为产物增产 |

默认新增农耕、钓鱼、附魔三个分类。农耕每收获 16 次成熟作物获得 1 点，五个单级“丰收学识”摆成麦穗形，各消耗 1 点、增加 1 点收获经验，学全合计 +5。左右两端分别连接“留种再耕”和“硕果累累”：各消耗 1 点，前者交付 1 把金锄开启自动补种，后者交付 1 个干草块获得 30% 增产。补种支持普通作物、下界疣、可可豆和破坏莓丛；右键采莓果保留原丛，不额外扣种。关闭方块掉落或恢复区块快照时不触发补种和增产。

钓鱼每成功钓获 4 次获得 1 点，包含各 3 级的“垂钓巧手”和“海洋馈赠”，每级消耗 1 点、无额外交付物品。按有物品的成功收杆次数计数，一次钓获多个物品仍只算一次。

钓鱼的两个普通技能下方各连接一个“幸运垂钓”大节点，各消耗 1 点和 16 个绿宝石，分别增加 1 点原版幸运，合计增加 2 点。

“奔跑”分类使用独立点数池，累计行走、奔跑和游泳 100 格获得 1 点，包括蹲走、水下和水面移动。距离采用原版厘米统计，保留不足一格的进度，不计传送、坐骑、飞行和鞘翅移动。三条分支各有五个依次连接的小节点，每个消耗 1 点：移速每节点增加 20%，累计 100%；跳跃每节点额外增加 0.2 格，累计 1 格；游泳使用 Forge 原生游泳速度属性，每节点增加 20%，累计 100%。每条分支末端连接单级大节点，消耗 1 点并交付 1 件物品：钻石靴子对应额外台阶高度 +1 格，羽毛对应摔落伤害减少 40%，海龟壳对应持续水下呼吸。三个大节点下方连接“御风飞行”，需完成这三个前置，消耗 1 点和 1 个鞘翅，增加 50% 鞘翅飞行速度。各分支属性随节点累加，不使用持续性奖励的等级替换规则。

“熔炼”分类每实际取出 8 个熔炼产物获得 1 点，普通领取和 Shift 领取都按实际迁出数量计点。15 个小节点各消耗 1 点并增加 10% 熔炼速度，累计 150%；第 5、10、15 个节点分别分出单级大节点“精炼增产”（粗矿翻倍概率 30%，交付 1 个远古残骸）、“节能炉膛”（燃料时间 +50%，交付 1 个煤炭块）、“炉火学识”（熔炼经验 +100%，交付 1 个经验瓶），各另消耗 1 点。

炉子绑定最后手动向原料或燃料格放入物品的玩家，普通点击与 Shift 投料均可绑定；仅打开、取出物品、漏斗续料不会转移归属。速度、点火时长、粗矿额外产物及经验倍率读取绑定玩家的在线属性；没有归属或玩家离线时使用原版行为。归属与小数进度保存在炉子 NBT，不添加旧存档迁移逻辑。

附魔分类没有技能池，包含 30 级“附魔精研”：第 N 级消耗 10×N 点实际经验值，满级累计消耗 4650 点。它连接四个单级大节点，每个消耗 100 点实际经验值，无额外交付物品：“青金节用”30% 概率不消耗青金石，“经验回流”返还本次附魔实际消耗经验的 30%，“书卷复刻”15% 概率获得相同附魔书副本，“先知之眼”预览全部词条。前三种交易收益只在非创造玩家真实附魔成功后结算，预览和无效点击不会发放收益。

经验余额由当前等级和经验条换算，升级只扣精确的经验点数并保留剩余经验条。删除、缩减等级或重置技能会按实际支付记录退还经验值或技能点；直接通过命令授予的等级不产生退款。分类中的“无技能池”只表示没有分配技能池；在每级编辑界面的消耗一行可独立切换“消耗经验值”或“消耗技能点”。技能点消耗使用分类所选技能池，没有技能池时不能设置非零技能点费用。

## 交付物品

每级除了点数，还可以要求交付最多 16 种物品，作为学习该等级的额外消耗。

- 学习时从主背包（含快捷栏）和副手中扣除，不检查盔甲栏，也不检查箱子、末影箱等容器。创造模式同样会扣除。
- 所有物品（技能图标、分类图标、交付物品）都通过点击物品格打开选择界面选择，分“全部物品”和“背包物品”两页，不再手填物品 ID 和 NBT。从“全部物品”选择时不带 NBT；从“背包物品”选择时会带上该物品的完整 NBT。
- NBT 为空时只按物品 ID 匹配，任何 NBT 的同种物品都算数，会优先扣除没有 NBT 的堆叠；填写 NBT 后，物品的 NBT 必须与填写内容完全一致（例如带附魔、耐久或自定义名称的物品，NBT 都不同）。
- 同一级的多个需求必须全部满足才能学习，同一堆物品不会被重复计算。
- 物品是一次性消耗：删除技能、缩减等级或 `/skillatlas reset` 只退还点数，不退还物品。
- 点数消耗可以设为 0，只用交付物品作为学习条件。
- 点数或物品不足时，技能显示为“资源不足”；学习前先检查点数，再检查物品。
- 填写的物品必须已在服务端注册，NBT 必须能被解析，否则保存会被拒绝。之后若移除了提供该物品的模组，对应等级无法再学习，需要编辑技能修正。

## 技能点

- 技能点存放在点数池中，每个分类指定一个点数池，多个分类可共用同一个池。点数池可设置名称、颜色和初始点数；初始点数在玩家首次加入或点数池新建后发放一次。
- 每个点数池绑定且只绑定一种获取方式，和点数池一起创建、编辑、删除：击杀生物、挖掘方块、收获成熟农作物、合成物品、熔炼物品、钓鱼、移动距离（格）、完成进度、游戏时长（秒）。
- 目标可填写注册 ID 或 `#标签`（进度除外），留空表示任意目标；没有目标的“完成进度”只统计会显示在进度界面里的进度。
- 所有标签名称（选择列表、已选目标和获取方式提示）统一使用语言键 `skill_atlas.tag.<命名空间>.<路径>`，路径中的 `/` 替换为 `.`。例如 `#c:ores` 对应 `skill_atlas.tag.c.ores`，显示为“矿物”；没有译文时显示原始 `#标签ID`，不会显示语言键。可通过资源包的 lang 文件添加译文，搜索同时支持译名、拼音和原始标签 ID。
- “击杀生物”可勾选“仅统计敌对生物”（默认勾选）：只有实现了原版 `Enemy` 接口的生物计数，包括所有怪物（含末影人、猪灵、僵尸猪灵等中立怪物）、史莱姆、岩浆怪、恶魂、幻翼、潜影贝、疣猪兽、末影龙等；狼、铁傀儡、动物和玩家不计数。同时指定了目标时，两个条件都要满足。
- 进度每达到“最大进度”一次给予指定点数，余数保留；“上限”限制该点数池通过获取方式最多给出的点数，0 为不限。
- “进度说明”用于告诉玩家如何获得进度，支持语言键、`&` 颜色代码和换行，显示在分类页签提示和“技能点”界面中，紧跟在获取方式和进度后面。进度说明是固定文本，修改最大进度或点数后需要同步修改说明。
- 玩家的进度和已获得点数按点数池 ID 记录。
- 创造与旁观模式默认不计入，可在服务端配置中开启；假玩家不计入。

## 文件

- 技能树定义：服务端 `config/skill_atlas/atlas.json`，保存时先写临时文件，旧文件备份为 `atlas.json.bak`。首次运行生成包含战斗、挖掘两个分类的示例。示例的挖掘分类：中间“急速”10 级，每级 +10% 挖掘速度，第 N 级消耗 N 点；左上“矿工之眼”消耗 4 点和 32 个金胡萝卜，获得持续夜视；右上“好运”3 级，每级 +1 时运，分别消耗 4 点 + 16 绿宝石、8 点 + 4 钻石、12 点 + 1 下界之星；左下“点石成金”5 级，每级增加 2% 石头出矿概率；右下“矿脉学识”5 级，每级增加 20% 矿物经验。两个下方技能均以急速为前置，每级消耗 1 点，不需要额外交付物品。已存在的定义文件不会被新版默认值自动覆盖。
- 示例的战斗分类由 8 条分支环绕中心组成：生命值、回血效率、攻击伤害、攻击速度、护甲、盔甲韧性、经验获取、抢夺。每条分支 11 个技能，均为 1 级；8 个小技能各消耗 1 点，分叉处的大技能消耗 3 点，两个末端大技能各消耗 4 点，大技能还需要交付物品，每点数获得的加成高于小技能。整棵战斗树共需 152 点。
- 翻译文本：`config/skill_atlas/lang/<语言>.json`，可直接交给译者编辑后执行 `/skillatlas reload`。旧配置中引用模组语言键（`skill_atlas.*`）的字段会在加载时自动迁移为生成的键。
- 玩家进度：存档 `data/skill_atlas_players.dat`。
- 定义文件加载失败时不会覆盖原文件，编辑功能会锁定，修复后执行 `/skillatlas reload`。
- 旧版 Skill Atlas 的 `atlas.json` 与玩家进度格式不兼容。旧定义会导致加载失败并锁定编辑；旧玩家进度不会被读取。

## 命令

需要权限等级 2。

| 命令 | 作用 |
| --- | --- |
| `/skillatlas reload` | 重新读取 `atlas.json` |
| `/skillatlas points get <玩家> <点数池>` | 查看点数 |
| `/skillatlas points add <玩家> <点数池> <数量>` | 增加点数（可为负数） |
| `/skillatlas points set <玩家> <点数池> <数量>` | 设置点数 |
| `/skillatlas reset <玩家> [技能]` | 重置全部或指定技能并退还点数 |
| `/skillatlas grant <玩家> <技能> [等级]` | 直接设置技能等级，省略等级时设为满级；授予的等级不产生退款记录 |

## 配置

服务端（存档 `serverconfig/skill_atlas-server.toml`）：

- `editPermissionLevel`：编辑所需权限等级，默认 2。
- `countCreativePlayers`：创造与旁观模式是否累计点数获取进度，默认 false。
- `notifyPointGain`：获得点数时是否在动作栏提示，默认 true。

客户端（`config/skill_atlas-client.toml`）：

- `virtualHeight`：界面虚拟高度，默认 360，越大界面越小。
- `panelWidth` / `panelHeight`：窗口占屏幕的比例。
- `showNodeNames`：缩放不低于 60% 时在技能下方显示名称。

## 性能提示

- 拼音索引按需计算。整合包物品、方块很多时，首次在选择器里输入搜索词可能有短暂卡顿（约 0.1 秒量级），之后使用缓存。
- 点数获取进度每次变化都会同步给该玩家，每 0.5 秒最多合并发送一次。存在获取方式为“游戏时长”的点数池时，每名在线玩家每秒会收到一次进度包（几百字节）。
- 画布每帧为可见的、下一级需要交付物品的技能扫描一次背包（41 格），组件解析结果有缓存，开销很小。
- 画布只绘制可见区域内的技能。同一分类有上千个技能且全部显示名称时，文字绘制会占用较多帧时间，可关闭 `showNodeNames` 或缩小视图。
