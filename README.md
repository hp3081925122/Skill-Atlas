# Skill Atlas 1.0.0

Minecraft 1.20.1、Forge 47.4.23、Java 17。客户端和服务端都安装正式 JAR；TinyPinyin 及其运行库已内置，无需安装其他模组。只针对上述版本开发和构建，不将元数据没有最高版本限制视为跨版本兼容证明。

## 操作

- 按 K 打开技能树，可修改按键。左侧切换分类，中键拖动画布，滚轮缩放至 25%～300%。点击技能查看当前奖励、下一等级奖励和成本，再学习下一等级。
- 搜索支持名称、Tooltip、中文、英文、无声调全拼、拼音首字母和自定义别名。搜索结果可滚动；点击结果切换分类并定位。多音字可通过别名补充。
- 权限等级至少 2 的管理员可开启编辑。单机需开启作弊并拥有对应权限。创造模式本身不授予编辑权限。
- 编辑时右键空白处创建节点，右键节点或点击“编辑选中”打开结构化表单。左键框选、Ctrl 点击多选，拖动选中节点整体移动，Delete 批量删除。
- Ctrl+C / Ctrl+V 支持跨分类复制。内部前置和连线重映射到新 ID；外部前置由粘贴对话框决定是否保留，默认可选择仅内部前置。Esc 取消粘贴。
- 批量修改时，只有明确开启“应用修改”的字段会被覆盖。奖励和前置列表的批量保存会整体替换对应列表。
- 等级上限先保存再编辑新增等级。各级分别配置成本和奖励；多选修改某一级时，所有选中节点必须已拥有该等级。
- 在“编辑等级”里设置点数数量及本等级使用的点数池，留空沿用所属分类。每个技能、每一级都可以消耗不同的技能点。多选时，点数数量和点数池各有独立的“应用修改”开关。
- 同一页面进入“交付物品”，添加物品 ID、数量和可选 NBT。学习该等级时，服务端同时检查前置、点数和物品；任何条件不足均不扣除，成功后一次性消耗。可以将点数成本设为 0，仅通过交付物品学习。
- 交付物品从主背包（包含快捷栏）和副手扣除，不包含盔甲栏、鼠标拿着的物品、潜影盒等容器内部或其他模组的额外背包。多个物品要求必须全部满足，可从多个堆叠扣除，同一批物品不会被重复计算。
- 交付物品 NBT 留空时只检查物品 ID；非空时必须与物品的完整 NBT 相等，键顺序不限，额外字段也会导致不匹配。例如 `{CustomModelData:7}` 只接受恰好带该 NBT 的对应物品。交付会消耗整个物品，不返还容器、耐久或物品内容，配置消耗贵重容器物品时需注意。
- 多选编辑交付物品时，保存只有在开启“应用修改：交付物品列表”后才替换所选节点该等级的列表；保存空列表可以取消交付要求。复制粘贴会保留物品要求及明确指定的点数池；继承分类的等级会使用粘贴目标分类的池。
- 节点名称、Tooltip、图标和前置都可修改。物品图标支持 NBT（例如 `{CustomModelData:1}`）；纹理填写资源包路径，例如 `your_pack:textures/gui/skill.png`。服务器只能校验纹理路径格式，客户端缺图显示占位图标。
- 前置支持跨分类及全部/任意条件。隐藏节点不会出现在普通玩家的搜索和连线中；编辑模式始终可见。隐藏仅是界面行为，客户端仍收到完整定义。
- 连线与前置独立。前置编辑器可以补充同分类连线，也可在“连线”菜单单独创建、隐藏或删除装饰连线。

## 分类、技能点与奖励

“分类与规则”菜单提供分类、点数池及获取规则编辑器。分类绑定点数池，共用同一池即可共享点数。所有规则独立结算，同一行为可命中多条规则。

规则目标支持注册 ID 和以 `#` 开头的标签，例如 `minecraft:zombie`、`#forge:ores`。次数模式累计指定次数发点并保留余数；经验模式每次行为增加指定池的经验。默认经验需求为 `100 + 50 × 当前经验等级`，每级 1 点，可在点数池中修改。

击杀计算真实玩家和其投射物的击杀，不计算玩家被杀。挖掘在非取消破坏且实际方块发生变化后记入。创造模式、旁观模式、假玩家不计入。玩家放置后再挖掘的矿石照常计数，允许重复放置刷进度。

每个技能最多 100 级，只使用当前等级奖励。属性支持加法、基础乘算及总值乘算；周期效果可配置等级、持续时间、间隔、粒子和图标，20 tick 为正常运行下的 1 秒；免疫按效果注册 ID 配置。效果等级参数从 0 开始，0 为一级。

升级会替换旧等级持续奖励。重连、死亡、换维度时重建奖励，属性不会反复累加。周期效果停止后不再刷新，已有短时效果自然到期。免疫会清除已有对应效果并拦截正常效果施加；免疫优先于周期效果。其他模组直接修改底层效果集合、绕过 Forge 事件的行为不在该拦截范围内。

普通玩家不能洗点。管理员重置会递归撤销失去前置的后续技能，并按实际支付记录退还原点数池。奖励扩展接口位于 `com.hp.skillatlas.api`，通过类型 ID 注册校验、应用与撤销处理；首版界面提供三种内置类型。

交付物品属于消耗品，管理员重置、删除节点或迁移撤销等级时不返还物品，只按历史记录退还技能点。修改物品要求或点数池不会向已学等级补收物品或补扣点数。已有定义缺少新的 `pool` / `items` 字段时，自动沿用分类点数池且不要求交付物品。

## 保存、导入导出与发布

- 生效定义：服务器 `config/skill_atlas/atlas.json`。
- 上一份有效定义：`atlas.previous.json`。
- 个人服务器草稿：`drafts/<UUID>.json`。
- 玩家进度：存档主世界 `data/skill_atlas_players.dat`，与定义文件分开保存。
- 游戏内“文件”菜单在服务器配置目录读写 JSON。文件名不含 `.json`，仅允许英文字母、数字、下划线和短横线。正式定义文件名 `atlas` 不允许作为导出目标。
- 导入只替换编辑草稿，点击“发布”才对玩家生效。导入前保留当前生效定义到 `import.previous.json`。
- 关闭未发布编辑时，可保存草稿或放弃。草稿保存检查结构和前置是否合法，失败后保留界面内容；只有服务器确认保存成功后才关闭。
- 发布检查循环、缺失前置、等级、点数、注册对象和标签等。纹理内容由客户端资源包提供；服务端不能证明其存在。
- 发布后保留兼容进度，删除、缩减等级或前置不满足的部分递归撤销并退款；离线玩家下次登录时迁移。修改成本不向已学习玩家补扣点数。
- 多管理员发布使用修订号防冲突。旧草稿需刷新，或在文件菜单明确选择替换当前版本并确认覆盖风险后重新发布。
- 仍有余额、经验等级或支付历史引用的点数池不允许删除。先调整或重置相关进度，再删除配置引用。

初次运行会生成战斗/挖掘两个分类、通用点数池、两级力量技能、一级急迫技能，以及每击杀 10 只僵尸/每挖掘 20 个矿石给 1 点的示例规则。

## 管理员命令

下列命令需要权限等级 2，玩家参数接受在线玩家或对应选择器。

```text
/skillatlas query <player>
/skillatlas points add <players> <pool> <amount>
/skillatlas points set <players> <pool> <amount>
/skillatlas experience add <players> <pool> <amount>
/skillatlas experience set <players> <pool> <totalExperience>
/skillatlas reset <players> <nodeId|*>
/skillatlas reload
```

`experience add` 正常升级并发点；`experience set` 按当前经验曲线重新计算总经验对应的等级和余量，保留现有点数，不再次发放升级奖励。`reload` 校验磁盘定义后发布，失败保留内存中的有效版本。

例如：`/skillatlas points add @s general 10`，`/skillatlas reset @s *`。
